How to use it

  1. Type the BPM of your session (or tap it from your DAW's tempo display).
  2. Read the millisecond value for the note division you want to hear — 1/4 for classic slap-back dub echoes, 1/8 dotted for the U2/Edge feel, 1/16 for tight vocal thickening.
  3. Enter the value into any delay plugin that isn't tempo-synced, or use the Hz column to set LFO rates on chorus, tremolo and auto-pan.

The formula

One beat (a quarter note) lasts 60,000 ÷ BPM milliseconds. Every other value is derived from that: halve it for an eighth, multiply by 1.5 for dotted, by 2/3 for triplet. The Hz column is simply 1000 ÷ ms — handy for rate-based modulation effects.

FAQ

Why sync delay to tempo at all?
Tempo-synced repeats sit inside the groove instead of smearing across it — the echoes reinforce the rhythm rather than fighting it. Unsynced delays are a deliberate creative choice, not a default.

What pre-delay should a vocal reverb have?
Start at the 1/64-note value for the song's tempo. It keeps the dry consonants intact (clarity) while the tail still locks to the track.
