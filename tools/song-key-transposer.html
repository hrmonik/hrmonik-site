FAQ

Transposing up or down — does it matter?
+2 and −10 semitones land on the same key name but a different octave feel. For vocals, choose the direction that keeps the melody inside the singer's comfortable range.

What's a relative minor?
The minor key that shares every note with a major key (A minor for C major). Same chords, different home base — which is why the tool shows it alongside the result.
